## TodoManager

会话级任务规划管理器，参考 learn-claude-code s03 Todo / Planning。

### Constructor

```javascript
new TodoManager(kernel)
```

### Methods

#### `update(items)`

更新 Todo 列表。

**Parameters:**
- `items` (Array): Todo 项列表
  - `content` (string): 任务内容

```javascript
const todoManager = kernel.todoManager;
const result = todoManager.update([
  { content: 'Read file', status: 'pending' },
  { content: 'Analyze code', status: 'in_progress', activeForm: 'Analyzing code' },
  { content: 'Write test', status: 'completed' },
]);
```

检查是否需要提醒更新计划。

**Example:**

#### `render()`

渲染 Todo 列表。

**Returns:** `string` - 渲染结果

#### `getState()`

获取当前状态。

**Returns:** `Object`
- `items` (Array): Todo 项列表
- `roundsSinceUpdate` (number): 未更新轮数
- `itemCount` (number): 总项数
- `completedCount` (number): 完成项数

#### `hasOpenItems()`

检查是否有开放的任务。

**Returns:** `boolean`

- `inProgress` (number): 进行中数
- `completed` (number): 已完成数
- `roundsSinceUpdate` (number): 未更新轮数

## TaskGraph

持久任务图管理器，参考 learn-claude-code s12 Task System。

### Constructor

```javascript
new TaskGraph(kernel)
```

### Methods

#### `create(subject, description)`

创建任务。

**Parameters:**
- `subject` (string): 任务主题
- `description` (string, optional): 任务描述

**Returns:** `Promise<Object>` - 创建的任务
- `id` (number): 任务 ID
- `subject` (string): 任务主题
- `description` (string): 任务描述
- `status` (string): 任务状态
- `blockedBy` (Array): 依赖任务 ID 列表
- `blocks` (Array): 阻塞任务 ID 列表
- `owner` (string): 任务所有者
- `createdAt` (number): 创建时间戳
- `updatedAt` (number): 更新时间戳

**Example:**
```javascript
const taskGraph = kernel.taskGraph;
const task = await taskGraph.create('Fix bug', 'Fix the critical bug in auth module');
// review: removed // review: removed // review: removed // review: removed // review: removed // review: removed // review: removed // review: removed // review: removed // review: removed // review: removed // review: removed // review: removed // review: removed console.log(task);
// { id: 1, subject: 'Fix bug', description: 'Fix the critical bug in auth module', ... }
```

#### `get(taskId)`

获取任务。

**Parameters:**
- `taskId` (number): 任务 ID

**Returns:** `Promise<Object | null>` - 任务对象或 null

#### `update(taskId, status, owner, addBlockedBy, addBlocks)`

更新任务。

**Parameters:**
- `taskId` (number): 任务 ID
- `status` (string, optional): 任务状态，可选值：`'pending'`, `'in_progress'`, `'completed'`, `'deleted'`
- `owner` (string, optional): 任务所有者
- `addBlockedBy` (Array, optional): 添加依赖任务 ID 列表
- `addBlocks` (Array, optional): 添加阻塞任务 ID 列表

**Returns:** `Promise<Object>` - 更新后的任务

**Example:**
```javascript
// 更新状态和所有者
await taskGraph.update(1, 'in_progress', 'agent-1');

// 添加依赖关系
await taskGraph.update(2, null, null, [1], null); // 任务 2 依赖任务 1
await taskGraph.update(1, null, null, null, [2]); // 任务 1 阻塞任务 2
```

#### `listAll()`

列出所有任务。

**Returns:** `Promise<Array>` - 任务列表

#### `delete(taskId)`

删除任务。

**Parameters:**
- `taskId` (number): 任务 ID

**Returns:** `Promise<boolean>` - 是否成功

#### `getStats()`

获取统计信息。

**Returns:** `Promise<Object>`
- `total` (number): 总数
- `pending` (number): 待处理数
- `inProgress` (number): 进行中数
- `completed` (number): 已完成数
- `deleted` (number): 已删除数
- `blocked` (number): 被阻塞数
- `blocking` (number): 阻塞其他任务数

#### `getDependencyGraph()`

获取依赖图。

**Returns:** `Promise<Object>`
- `nodes` (Array): 节点列表
  - `id` (number): 任务 ID
  - `subject` (string): 任务主题
  - `status` (string): 任务状态
  - `blockedBy` (Array): 依赖任务 ID 列表
  - `blocks` (Array): 阻塞任务 ID 列表
- `edges` (Array): 边列表
  - `from` (number): 源任务 ID
  - `to` (number): 目标任务 ID
  - `type` (string): 边类型

## AutonomousAgentManager

自主代理管理器，参考 learn-claude-code s17 Autonomous Agents。

### Constructor

```javascript
new AutonomousAgentManager(kernel)
```

### Methods

#### `initialize()`

初始化管理器。

**Returns:** `Promise<void>`

#### `registerAgent(config)`

注册代理。

**Parameters:**
- `config` (Object): 代理配置
  - `id` (string, optional): 代理 ID
  - `name` (string): 代理名称
  - `capabilities` (Array, optional): 能力列表

**Returns:** `string` - 代理 ID

**Example:**
```javascript
const agentManager = kernel.autonomousAgentManager;
await agentManager.initialize();

const agentId = agentManager.registerAgent({
  name: 'code-reviewer',
  capabilities: ['code', 'review', 'analysis'],
});
```

#### `submitTask(task)`

提交任务。

**Parameters:**
- `task` (Object): 任务配置
  - `id` (string, optional): 任务 ID
  - `subject` (string): 任务主题
  - `description` (string): 任务描述
  - `priority` (string, optional): 优先级，可选值：`'critical'`, `'high'`, `'normal'`, `'low'`
  - `requiredCapabilities` (Array, optional): 所需能力列表
  - `dueAt` (number, optional): 截止时间戳

**Returns:** `string` - 任务 ID

**Example:**
```javascript
const taskId = agentManager.submitTask({
  subject: 'Review PR #123',
  description: 'Review the pull request for bug fix',
  priority: 'high',
  requiredCapabilities: ['code', 'review'],
});
```

#### `getAgentStats(agentId)`

获取代理状态。

**Parameters:**
- `agentId` (string): 代理 ID

**Returns:** `Object | null`
- `id` (string): 代理 ID
- `name` (string): 代理名称
- `capabilities` (Array): 能力列表
- `status` (string): 代理状态
- `currentTask` (Object): 当前任务
- `stats` (Object): 统计信息
  - `tasksCompleted` (number): 已完成任务数
  - `tasksFailed` (number): 失败任务数
  - `totalDuration` (number): 总耗时

#### `getStats()`

获取统计信息。

**Returns:** `Object`
- `totalAgents` (number): 总代理数
- `idleAgents` (number): 空闲代理数
- `workingAgents` (number): 工作代理数
- `pendingTasks` (number): 待处理任务数
- `runningTasks` (number): 运行中任务数
- `completedTasks` (number): 已完成任务数
- `failedTasks` (number): 失败任务数

#### `shutdown()`

停止管理器。

**Returns:** `Promise<void>`

## WorktreeTaskBinding

Worktree 任务双向绑定管理器。

### Constructor

```javascript
new WorktreeTaskBinding(kernel)
```

### Methods

#### `bindTaskToWorktree(taskId, worktreeName)`

绑定任务到 Worktree。

**Parameters:**
- `taskId` (string): 任务 ID
- `worktreeName` (string): Worktree 名称（格式：`{teamId}/{memberName}`）

**Returns:** `Promise<void>`

#### `worktreeCloseout(worktreeName, action, reason, completeTask)`

关闭 Worktree。

**Parameters:**
- `worktreeName` (string): Worktree 名称
- `action` (string): 关闭动作，可选值：`'merge'`, `'abandon'`, `'defer'`
- `reason` (string): 关闭原因
- `completeTask` (boolean, optional): 是否完成任务

**Returns:** `Promise<void>`

#### `getBindingStatus(worktreeName)`

获取绑定状态。

**Parameters:**
- `worktreeName` (string): Worktree 名称

**Returns:** `Promise<Object>`
- `task` (Object): 任务信息
- `worktree` (Object): Worktree 信息
- `binding` (Object): 绑定信息

## PlanApprovalManager

计划审批管理器，参考 learn-claude-code s16 Team Protocols。

### Constructor

```javascript
new PlanApprovalManager(kernel)
```

### Methods

#### `requestApproval(teammateName, plan)`

请求审批。

**Parameters:**
- `teammateName` (string): 队友名称
- `plan` (Object): 计划内容

**Returns:** `Promise<string>` - 请求 ID

#### `respond(requestId, decision, reason)`

响应审批。

**Parameters:**
- `requestId` (string): 请求 ID
- `decision` (string): 审批决定，可选值：`'approve'`, `'reject'`
- `reason` (string): 审批原因

**Returns:** `Promise<Object>`
- `requestId` (string): 请求 ID
- `status` (string): 请求状态
- `decision` (string): 审批决定
- `reason` (string): 审批原因

#### `getPendingRequests(teammateName)`

获取待审批请求。

**Parameters:**
- `teammateName` (string, optional): 队友名称

**Returns:** `Array` - 待审批请求列表

#### `getRequest(requestId)`

获取请求详情。

**Parameters:**
- `requestId` (string): 请求 ID

**Returns:** `Object | null` - 请求详情

#### `getStats()`

获取统计信息。

**Returns:** `Object`
- `total` (number): 总请求数
- `pending` (number): 待审批数
- `approved` (number): 已批准数
- `rejected` (number): 已拒绝数

## MessageBus

团队消息总线，参考 learn-claude-code s15 Agent Teams。

### Constructor

```javascript
new MessageBus(kernel, options)
```

### Methods

#### `send(sender, to, content, msgType, extra)`

发送消息。

**Parameters:**
- `sender` (string): 发送者名称
- `to` (string): 接收者名称
- `content` (string): 消息内容
- `msgType` (string, optional): 消息类型，可选值：`'message'`, `'broadcast'`, `'shutdown_request'`, `'shutdown_response'`, `'plan_approval_request'`, `'plan_approval_response'`
- `extra` (Object, optional): 额外信息

**Returns:** `string` - 发送结果

#### `readInbox(name)`

读取收件箱。

**Parameters:**
- `name` (string): 收件人名称

**Returns:** `Array` - 消息列表

#### `broadcast(sender, content, teammates)`

广播消息。

**Parameters:**
- `sender` (string): 发送者名称
- `content` (string): 消息内容
- `teammates` (Array): 团队成员列表

**Returns:** `string` - 发送结果
