# HundunOS v4.3 使用指南

## 概述

HundunOS v4.3 引入了多项新功能，参考 learn-claude-code 的设计理念，提升了上下文管理、错误恢复、团队协作和自主任务处理能力。

### 主要新功能

1. **Compact 三层压缩机制** - 智能上下文压缩，减少 token 消耗
2. **Recovery TransitionReason 状态机** - Agent 级错误恢复
3. **Memory Frontmatter 规范** - 结构化记忆管理
4. **PromptParts 模块化组装** - 灵活的 prompt 组装
5. **Worktree 任务双向绑定** - 任务与 worktree 关联
6. **Team Plan Approval 协议** - 团队协作审批
7. **Todo 轻量清单系统** - 会话级任务规划
8. **TaskGraph 持久任务图** - 跨会话任务管理
9. **Autonomous Agents 自主认领** - 自动任务调度

## Compact 三层压缩机制

### 工作原理

1. **第一层：PersistedOutputMarker**
   - 大于 50KB 的工具输出自动持久化到磁盘
   - 保留 2KB 预览

2. **第二层：Microcompact**
   - 保留最近 3 个工具结果
   - 旧工具结果替换为摘要

3. **第三层：LLM Summarization**
   - 使用 GPT-4o-mini 生成摘要
   - 保留最近消息和系统提示

### 配置

```json
{
  "compact": {
    "contextWindowThreshold": 8000,
    "summaryModel": "gpt-4o-mini",
    "maxSummaryTokens": 500,
    "microCompactEnabled": true,
    "keepRecentToolResults": 3
  }
}
```

## Recovery TransitionReason 状态机

### 支持的恢复动作

- `CONTINUE` - 注入续写提示（用于 max_tokens 截断）
- `COMPACT_AND_RETRY` - 压缩上下文后重试（用于 context 超限）
- `RESTART` - 重启会话
- `ROLLBACK` - 回滚到上一个状态
- `RELOAD` - 重新加载模块
- `ESCALATE` - 升级到人工干预
- `IGNORE` - 忽略错误

### 使用示例

```javascript
const recovery = kernel.recovery;
await recovery.handle({
  type: 'agent_error',
  error: 'max_tokens',
  context: { sessionId: 'session-123' },
});
// 自动注入续写提示
```

## Memory Frontmatter 规范

### Frontmatter 格式

```yaml
---
name: "User prefers dark mode"
description: "User consistently chooses dark theme in UI settings"
type: "user"
scope: "private"
tags: ["preference", "ui"]
createdAt: "2025-01-15T10:30:00Z"
updatedAt: "2025-01-15T10:30:00Z"
---

User preferred dark mode in the last 3 sessions.
```

### 类型说明

- `user` - 用户偏好和行为
- `feedback` - 用户反馈
- `project` - 项目相关信息
- `reference` - 参考资料和文档

### 作用域说明

- `private` - 仅当前会话可见
- `team` - 团队共享

## PromptParts 模块化组装

### 基本用法

```javascript
import { PromptParts, buildSystemPrompt } from './kernel/prompts/prompt-parts.js';

const parts = new PromptParts()
  .setCoreIdentity('You are a helpful coding assistant.')
  .setMemorySection(memorySection)
  .setSkillSection(skillSection)
  .setTaskContext(taskContext)
  .setToolGuidance(toolGuidance);

const systemPrompt = parts.build();
```

### 在压缩后使用

```javascript
const compressedPrompt = buildSystemPrompt({
  coreIdentity: kernel.config.systemPrompt,
  memorySection: prioritizedMemories,
  skillSection: skillContext?.injectedSkills || [],
  taskContext: session?.context?.reminder || '',
  toolGuidance: toolGuidance,
});
```

## 最佳实践

### 1. Todo 使用

- 对于简单任务，使用 Todo 工具
- 限制在 12 项以内
- 确保只有一项处于 `in_progress` 状态

### 2. TaskGraph 使用

- 对于需要跨会话追踪的任务，使用 TaskGraph
- 合理设置依赖关系
- 及时更新任务状态

### 3. Autonomous Agents 使用

- 为代理设置明确的能力列表
- 使用优先级控制任务执行顺序
- 监控代理统计信息

### 4. Worktree 使用

- 在团队协作场景中使用 Worktree 隔离
- 完成任务后及时关闭 Worktree
- 选择合适的合并策略

### 5. Compact 配置

- 根据模型上下文窗口调整阈值
- 使用成本优化的模型进行摘要
- 启用 microcompact 减少摘要频率

## 故障排除

### Todo 工具不可用

```javascript
if (!kernel.todoManager) {
  console.error('TodoManager not initialized');
}
```

### TaskGraph 持久化失败

检查存储目录权限：
```bash
ls -la .hundunos/tasks
```

### Autonomous Agents 不工作

```javascript
const stats = kernel.autonomousAgentManager.getStats();
```

### Worktree 创建失败

```bash
git rev-parse --is-inside-work-tree
```
