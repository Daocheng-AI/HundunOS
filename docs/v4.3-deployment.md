## 环境要求

### 最低要求

- Node.js >= 18.0.0
- Python >= 3.8
- 8GB RAM
- 10GB 磁盘空间

### 推荐配置

- Node.js >= 20.0.0
- Python >= 3.10
- 16GB RAM
- 50GB SSD

## 安装

### 从源码安装

```bash
git clone https://github.com/hundunos/hundunos.git
cd hundunos
npm install
```

### 使用 Docker 安装

```bash
docker pull hundunos/hundunos:latest
docker run -d -p 38080:38080 -p 9090:9090 hundunos/hundunos:latest
```

## 配置

### 环境变量

```bash
# 加密密钥（生产环境必须）
export HUNDUNOS_ENCRYPTION_KEY="your-32-char-encryption-key"

# OpenAI API Key
export OPENAI_API_KEY="your-openai-api-key"

# Anthropic API Key
export ANTHROPIC_API_KEY="your-anthropic-api-key"

# 工作目录
export HUNDUNOS_WS="/path/to/workspace"

# 存储目录
export HUNDUNOS_STORAGE=".hundunos"
```

### 配置文件

编辑 `config/system.json`：

```json
{
  "version": "4.3.0",
  "environment": "production",

  "compact": {
    "enabled": true,

    "enabled": true,

    "enabled": true,
    "storageDir": ".hundunos/tasks"

    "enabled": true,
    "pollInterval": 5000,
    "maxConcurrency": 5
  },
  "monitoring": {
    "enabled": true,

  "locale": "zh"

```

## 部署方式

### 1. 直接部署

```bash
npm start
```

### 2. PM2 部署

```bash
npm install -g pm2
pm2 start npm --name "hundunos" -- start
pm2 save
pm2 startup
```

### 3. Docker 部署

```dockerfile
FROM node:20-alpine

WORKDIR /app

COPY package*.json ./
RUN npm ci --only=production

COPY . .

EXPOSE 38080 9090

CMD ["npm", "start"]
```

构建和运行：

```bash
docker build -t hundunos .
docker run -d -p 38080:38080 -p 9090:9090 --name hundunos hundunos
```

### 4. Kubernetes 部署

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: hundunos
spec:
  replicas: 2
  selector:
    matchLabels:
      app: hundunos
  template:
    metadata:
      labels:
        app: hundunos
    spec:
      containers:
      - name: hundunos
        image: hundunos/hundunos:latest
        ports:
        - containerPort: 38080
        - containerPort: 9090
        env:
        - name: HUNDUNOS_ENCRYPTION_KEY
          valueFrom:
            secretKeyRef:
              name: hundunos-secrets
              key: encryption-key
        - name: OPENAI_API_KEY
          valueFrom:
            secretKeyRef:
              name: hundunos-secrets
              key: openai-api-key
        resources:
          requests:
            memory: "1Gi"
            cpu: "500m"
          limits:
            memory: "4Gi"
            cpu: "2000m"
---
apiVersion: v1
kind: Service
metadata:
  name: hundunos
spec:
  selector:
    app: hundunos
  ports:
  - port: 38080
    targetPort: 38080
    name: api
  - port: 9090
    targetPort: 9090
    name: metrics
  type: LoadBalancer
```

部署：

```bash
kubectl apply -f k8s.yaml
```

## 监控

### Prometheus 指标

HundunOS 在端口 9090 暴露 Prometheus 指标：

```bash
curl http://localhost:9090/metrics
```

主要指标：

- `hundunos_tool_executions_total` - 工具执行次数
- `hundunos_llm_requests_total` - LLM 请求次数
- `hundunos_compactions_total` - 压缩次数
- `hundunos_errors_total` - 错误次数
- `hundunos_active_sessions` - 活跃会话数
- `hundunos_pending_tasks` - 待处理任务数
- `hundunos_tool_execution_duration_seconds` - 工具执行耗时
- `hundunos_llm_request_duration_seconds` - LLM 请求耗时
- `hundunos_token_usage` - Token 使用量

### Prometheus 配置

```yaml
scrape_configs:
  - job_name: 'hundunos'
    static_configs:
      - targets: ['localhost:9090']
```

## 备份

### 备份策略

1. **配置文件备份**

```bash
tar -czf config-backup-$(date +%Y%m%d).tar.gz config/
```

2. **数据备份**

```bash
tar -czf data-backup-$(date +%Y%m%d).tar.gz .hundunos/
```

3. **定期备份脚本**

```bash
#!/bin/bash
# backup.sh

BACKUP_DIR="/backups/hundunos"
DATE=$(date +%Y%m%d)
mkdir -p $BACKUP_DIR

# 备份配置
tar -czf $BACKUP_DIR/config-$DATE.tar.gz config/

# 备份数据
tar -czf $BACKUP_DIR/data-$DATE.tar.gz .hundunos/

# 保留最近 30 天的备份
find $BACKUP_DIR -name "*.tar.gz" -mtime +30 -delete
```

### 恢复

```bash
# 恢复配置
tar -xzf config-backup-20250115.tar.gz -C /

# 恢复数据
tar -xzf data-backup-20250115.tar.gz -C /
```

## 故障排除

### 常见问题

#### 1. 内存不足

**症状**：进程崩溃，OOM 错误

**解决方案**：
- 增加内存限制
- 启用 Compact 三层压缩
- 减少 `maxHistoryRounds`

```json
{
  "compact": {
    "contextWindowThreshold": 6000,
    "maxHistoryRounds": 5
  }
}
```

#### 2. LLM API 限流

**症状**：429 错误，请求失败

**解决方案**：
- 启用 RetryManager
- 配置多个 Provider
- 使用本地模型作为降级

```json
{
  "modelRouter": {
    "providers": ["ollama", "openai", "anthropic"],
    "localFirst": true
  }
}
```

#### 3. Worktree 创建失败

**症状**：Git 不可用，降级到 fork 模式

**解决方案**：
- 确保 Git 已安装
- 检查 Git 仓库状态
- FallbackManager 自动降级

#### 4. MCP 连接失败

**症状**：MCP 工具不可用

**解决方案**：
- 检查 MCP 配置文件
- 确认 MCP 服务器运行正常
- 查看 MCP 错误日志

#### 5. 加密密钥错误

**症状**：`HUNDUNOS_ENCRYPTION_KEY required in production`

**解决方案**：
```bash
export HUNDUNOS_ENCRYPTION_KEY="your-32-char-encryption-key"
```

## 安全建议

1. **生产环境必须设置加密密钥**
   ```bash
   export HUNDUNOS_ENCRYPTION_KEY="your-32-char-encryption-key"
   ```

2. **使用 HTTPS**
   ```nginx
   server {
       listen 443 ssl;
       ssl_certificate /path/to/cert.pem;
       ssl_certificate_key /path/to/key.pem;
       
       location / {
           proxy_pass http://localhost:38080;
       }
   }
   ```

3. **启用审计日志**
   ```json
   {
     "auditLogger": {
       "enabled": true
     }
   }
   ```

4. **配置访问控制**
   ```json
   {
     "accessControl": {
       "enabled": true,
       "defaultRoles": ["guest"]
     }
   }
   ```

5. **定期更新依赖**
   ```bash
   npm audit fix
   npm update
   ```

## 升级

### 从 v4.1 升级到 v4.3

1. 备份数据
   ```bash
   tar -czf backup-v4.1.tar.gz .hundunos/
   ```

2. 更新代码
   ```bash
   git pull origin main
   npm install
   ```

3. 更新配置文件
   - 添加新的配置节
   - 检查环境变量

4. 重启服务
   ```bash
   pm2 restart hundunos
   ```

5. 验证升级
   ```bash
   curl http://localhost:38080/api/health
   ```
